# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Muse Agent and user sandboxes seriously.

If you believe you have discovered a vulnerability in Muse Agent:
1. **Do not disclose the issue publicly.**
2. Send an email to [khandalraghav4@gmail.com](mailto:khandalraghav4@gmail.com) with the subject:
   `[SECURITY] Vulnerability in Muse Agent - <Brief Description>`.
3. Include detailed steps to reproduce the issue, proof of concept code, and relevant environment details.

### Response Timeline
- **Acknowledgement**: Within 24-48 hours.
- **Triage & Patching**: Critical security patches will be pushed to `main` and tagged in a patch release within 3-7 days.
- **Public Disclosure**: Coordinated after users have had reasonable time to upgrade.
