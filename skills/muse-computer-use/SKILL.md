# Muse Computer-Use Agent (CUA) Skill

Provides autonomous operating system automation tools for AI coding agents.

## Core Actions
- `desktop_capture_screenshot`: Capture 1080p/4K multi-monitor desktop buffer.
- `cua_click_coordinate`: Precise pixel-level click, double-click, and drag.
- `cua_type_text`: Human-like typing with configurable delays.
- `active_window_inspect`: Identify foreground windows, processes, and bounding boxes.
- `routine_execute_chain`: Sequential execution of automated desktop routines.
